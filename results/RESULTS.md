# Results

Generated by `bench/make_results_table.py` from 82 result records in `results/`. Scores are `points/possible` as written by the runner. **Direct-API rows and harness-assisted rows are separate experiments and must not be compared with each other**, and a /500 v2 total is not comparable with a /400 tiebreaker total. Every row is a single run unless the Runs column says otherwise; single runs of the tiebreakers are noisy (see README Findings).

Legend: **Date** = modification date of the original result file (from `MANIFEST.json`). **Engine / harness** = serving stack parsed from the run's display string for direct-API rows (`n/a` when it was not recorded), or the agent harness for harness-assisted rows. **INCONCLUSIVE** tasks (timeouts / token caps) are excluded from that row's total by the newer runners; older files scored API errors as 0 and are flagged. Display strings mention the machine the server ran on (Beast = 2x RTX PRO 6000 Linux box, Cosmo/Sentry = Mac Studio M3/M4 Ultra) and, for local models, the quantisation.
